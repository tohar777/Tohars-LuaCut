# Tohars LuaCut
<p>LuaCut is a script and automation management software making simple automations like creating a file with a custom  template easy and simple using the lua scripting language.</p>

## Why I chose lua?: 

Lua is a simple scripting language that everyone can learn even with no programming background unlike for example C or Java which makes you learn concepts like pointers(C) or some data types(Both languages). Lua utilises the english language which even a person with a small vocabulary can learn.

## Current Features
- A GUI for script management
- Supporting the standard lua libraries
- Low-Level API `lc_*` with currently only filesystem support

## Upcoming Features:
- `.bundle` a xml-based format for combing lua and html,css for a more customizable UI
- LCAPI ImGui window creation,hotkeys
